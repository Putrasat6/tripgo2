TRIPGO - WEBSITE AGEN PERJALANAN WISATA

CARA MENJALANKAN
1. Ekstrak file TripGo-Website.zip.
2. Buka folder TripGo menggunakan Visual Studio Code.
3. Jalankan index.html dengan Live Server atau buka langsung di browser.
4. Pastikan internet aktif agar foto Unsplash dan Google Fonts dapat dimuat.

HALAMAN
- index.html: Beranda
- destinasi.html: Daftar destinasi, pencarian, filter, detail pop-up
- paket.html: Paket wisata dan fasilitas
- pemesanan.html: Formulir dan kalkulator estimasi biaya
- tentang.html: Profil TripGo
- kontak.html: Formulir kontak simulasi

FITUR JAVASCRIPT
- Pop-up detail destinasi
- Pop-up cara memesan
- Kalkulator estimasi biaya
- Filter dan pencarian destinasi
- Konfirmasi simulasi pemesanan
- Validasi formulir HTML
- Penyimpanan data simulasi pemesanan menggunakan LocalStorage
- Menu navigasi responsif untuk ponsel

CATATAN
Website tidak menggunakan database, server, atau backend. LocalStorage hanya menyimpan data di browser pengguna. Formulir kontak dan pemesanan adalah simulasi, bukan transaksi atau reservasi nyata. Harga, kontak, dan isi destinasi adalah data contoh. Silakan sesuaikan untuk tugas.
